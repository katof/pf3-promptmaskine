# PF3 Promptmaskine

Værktøj til Portfolio 3 (GenAI kritisk betragtet) i valgfaget GenAI 2026, Aarhus Universitet.

Byg en prompt ud fra jeres holdning og jeres tekster, sæt AI'ens svar ind, og find ud af, hvem der taler i svaret: teorien, jer eller AI'en selv.

- Ingen tekster ligger i maskinen. Indsæt eller upload jeres egne (.md eller .txt) under trin 1. Afsnit nummereres automatisk.
- Alt gemmes kun i din egen browser. Brug "Gem forsøget som fil" for at flytte et forsøg til en anden computer.

Åbn: https://katof.github.io/pf3-promptmaskine/
